One razor-sharp line that gets you out of a pointless work meeting.

## Run

Node 22.18 or later (the grader uses Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes exactly one UTF-8 line to `/output/entry.txt`. No dependencies,
no network calls, no environment secrets.
